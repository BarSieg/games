# 07 · Hordenheld

_In Arbeit._ Überleben gegen Hunderte Gegner auf einmal, im Stil von Vampire Survivors. Man steuert nur die Laufrichtung, die Waffen feuern von selbst. Besiegte Gegner lassen Edelsteine fallen, und mit jedem Level gibt es ein Upgrade.

Dieses Spiel baue ich selbst im Editor, Kapitel für Kapitel. Wie es entsteht, steht in der [ANLEITUNG.md](ANLEITUNG.md), mit allen Übungsaufgaben.

**Starten:**
- **Im Editor:** Ordner in 🆓 Godot 4 öffnen und **F5** drücken.

**Steuerung:**
- **Xbox-Controller:** Stick oder D-Pad: Laufen
- **Tastatur:** Pfeiltasten oder WASD: Laufen
